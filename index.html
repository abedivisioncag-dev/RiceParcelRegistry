📄 GeoJSON Format
Export your parcels from QGIS or ArcGIS as a GeoJSON file. Make sure each feature has a geometry (Polygon) and a properties object with farmer info.
🗺 Shapefile Format
Zip your .shp + .dbf + .prj files together into a single .zip archive, then upload the zip. The dashboard will automatically convert it to GeoJSON. Make sure all three files have the same base name (e.g. parcels.shp, parcels.dbf, parcels.prj).
⚙️ Field Mapping
After uploading, you'll see a Field Mapping step. Match your file's column names to the dashboard fields (Farmer Name, Area, Farm Location, etc.). This lets the dashboard work with any column naming convention.
💾 Data Persistence
Imported data is saved in your browser (localStorage) so it persists after refreshing. Use the Manage Data tab to view, delete individual parcels, export, or reset back to the built-in sample data.
📋 Recommended Column Names
farmer_nam — Farmer full name
last_name — Last name
area_ha — Area in hectares
barangay — Farm Location (barangay)
rsbsa_no — RSBSA No
parcel_id — Parcel ID
